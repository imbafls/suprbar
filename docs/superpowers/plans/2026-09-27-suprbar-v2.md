# supr.bar v2.0 — implementation plan

Spec: `docs/superpowers/specs/2026-09-27-suprbar-v2-design.md`.

Every task ends with the **gate**: `python -m pytest -q`, `python -m ruff
check suprbar`, `python -m mypy suprbar`, `python -m mypy --platform linux
suprbar` all green, plus the task's own check. One task per loop
iteration; commit after each.

Removal tasks go first (consumers stop reading a setting), the config
schema changes after them (nothing left reads the dropped keys), the new
UI last (it targets the final API).

## T1 — Remove budgets
- Delete `scanner.budgets_summary`; tray `_latest_budgets`,
  `_notify_budget_crossings`, palette tint (`warn`/`danger` icons),
  `_icon_cache` palette keys; server `/api/budgets` + `_budgets_payload`;
  `config.project_limit_map` and budget helpers; tests
  `ProjectBudgetTest`, `ProjectLimitParseTest`.
- Check: `grep -ri budget suprbar/*.py` finds nothing but the schema
  (removed in T5); gate.

## T2 — Remove project filters, anonymize, top-N
- Drop `allowlist`/`denylist`/`anonymize` parameters from
  `scanner.today_summary`/`range_summary` and every caller (server,
  report, aggregator, providers); delete `config.project_allowlist`,
  `project_denylist`, `anonymize_projects`, top-N use.
- Check: grep clean; `range_summary("30d")` totals unchanged vs before
  (quick script); gate.

## T3 — Fixed flyout, no click-through
- `popup.py`: placement always bottom-right of the cursor's monitor
  (12 px margin), fixed 360×480, `easy_drag=False`; delete window-state
  x/y/w/h persistence, snap, resize, `on_moved`/`on_resized`,
  click-through, `resize_window`/`apply_click_through`/`apply_mini`
  JS API; always on top.
- `mini.py`: delete click-through. `windows.py`/`windowhost.py`/`tray.py`:
  delete `click_through` commands and menu items.
- Check: child harness — show, toggle hide, show; window rect equals the
  expected bottom-right rect; gate.

## T4 — Fixed internals
- `pricing.remote_url` → module constant; log level fixed INFO
  (`SUPRBAR_LOG` still honoured); live threshold fixed 60 s; range
  day-boundary/rolling/weekends/week-start prefs removed (scanner
  defaults); server today cache TTL 4 s live / 25 s idle.
- Check: grep for each removed pref clean outside `config.py`; gate.

## T5 — Config schema v5 (tests first)
- Test: v4 fixture (with keys, pin, auto_hide False, budgets, display…)
  migrates to v5: sources + keys + mini.enabled + start_on_login +
  updates kept, `ui.pinned` merged, everything else gone; v5 round-trips;
  unknown keys ignored.
- Implement `SCHEMA_VERSION = 5`, new DEFAULTS/SCHEMA (the 5 settings +
  internal update keys), `_migrate` v4→v5; delete accessors for dropped
  settings.
- Check: new test passes; migrating a copy of the real
  `%APPDATA%\suprbar\config.json` keeps both encrypted key fields
  byte-identical; gate.

## T6 — Settings API (tests first)
- Test (`tests/test_server_settings.py`, real server on a free port,
  config dir redirected to a temp dir): `GET /api/settings` has no
  plaintext keys; `POST /api/settings` applies each of the 5 settings,
  rejects unknown paths with 400; key set + clear; test-key validates
  `source`; removed routes 404.
- Implement `/api/settings`, `/api/settings/test-key`; delete
  `/api/config*`, `/api/prefs*`, `/api/open-path`, `/api/health`,
  `/api/diagnostics` and their helpers; `start_on_login` change applies
  the Run key immediately; `mini.enabled` change calls the tray's mini
  sync (server gets a settings-changed callback from `__main__`).
- Check: test passes; gate.

## T7 — Tray trim + clean quit
- Menu: Open (default) · Mini overlay ✓ · Refresh · 30-day report ·
  Settings… · (Update to vX…) · Quit. Periodic 6 h update check obeys
  `updates.check_on_launch`. Shutdown: stop children (5 s), stop icon,
  6 s `os._exit` watchdog in the tray process.
- Check: source instance — menu item count via pystray `Menu` object in a
  quick script; quit via `/api/quit` exits in < 7 s with no leftover
  `--window` processes; gate.

## T8 — New flyout page
- Rewrite `static/index.html` (≤ 120 lines) and `static/app.js`
  (≤ 450 lines) per the spec: header/status, 4 tabs, hero, sources line,
  bars, projects, models, footer with Report + update button, settings
  sheet against `/api/settings`; polling rules (5 s / 30 s visible, none
  hidden, backoff when offline); `window.__suprbarVisible`.
- Check: browser pane at 360×480 against a source server shows every
  section with real data, tab switch works, settings sheet toggles
  persist (re-GET); gate.

## T9 — Trim styles.css
- Keep dark tokens + indigo accent + the rules the new pages use; delete
  the rest. ≤ 450 lines.
- Check: screenshots of flyout + settings unchanged in look vs T8; no
  class in index.html/app.js without a rule (quick grep script); gate.

## T10 — Trim the mini overlay
- `mini.html`/`mini.js`/`mini.css`: chip (dot, 24h cost, $/h) + hover
  card (today cost, messages, project); polls 5 s / 30 s; × disables.
  No prefs fetch, no budget bar, no range toggle.
- Check: browser pane renders `/mini.html` chip; harness mini on/off;
  gate.

## T11 — Blank-flyout guard
- Child: first `show` waits for pywebview `loaded` (max 3 s) before
  showing; later shows immediate.
- Check: harness — cold show emits `shown` after page load, screenshot
  of the window area isn't blank (or DOM check via evaluate_js); gate.

## T12 — Scanner rollover + index equality tests
- `tests/test_scanner_rollover.py`: temp CLAUDE_HOME fixture; today
  totals reset across local midnight (monkeypatched clock); per-day index
  range == exact scan for the same whole-day window.
- Check: tests pass; gate.

## T13 — UI smoke test + dead-code sweep
- `tests/test_ui_smoke.py` updated to the new ids (flyout + mini).
- Sweep: grep for every removed name/route/setting across `suprbar/`,
  `tests/`, `static/`; delete leftovers (`report.html` fetches, unused
  JS/CSS, server docstring route list).
- Check: sweep grep list prints nothing; gate.
